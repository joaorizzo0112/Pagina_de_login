# 🔐 Páginas de Autenticação (Login, Cadastro e Recuperação)

## Descrição

Este é um projeto prático de construção de interfaces web estáticas. O principal objetivo deste repositório é demonstrar a criação de um fluxo de autenticação com telas simples, modernas e esteticamente agradáveis. 

O projeto foi desenvolvido para consolidar conhecimentos básicos de estruturação e estilização de páginas web, focando no aprendizado como iniciante na área de desenvolvimento front-end.

## Estrutura do Projeto

O repositório é composto pelas seguintes interfaces interligadas:
- **Tela de Login (`index.html` / `style.css`):** Tela de acesso principal com campos para credenciais.
- **Tela de Criação de Conta (`criar_conta.html` / `conta.css`):** Formulário focado no registro de um novo usuário.
- **Tela de Redefinição de Senha (`recupera_senha.html` / `senha.css`):** Interface dedicada para recuperação de acesso.

## Tecnologias Utilizadas

Este projeto foi construído utilizando exclusivamente tecnologias base da web:

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Marcação e estruturação semântica dos formulários e elementos.
- **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Estilização do layout, cores, tipografia, transições e organização visual das telas.
